## Boundary

The competition module is operationally separate from SSI core theory.

- Competition results may provide external rebounds and diagnostics.
- A leaderboard result does not automatically update SSI theory.
- Closed competition branches remain closed unless new evidence explicitly reopens them.
- Competition data, organizer-owned media, and non-redistributable derived data are not committed here.
- Frozen hashes and provenance may be committed so local artifacts can be verified without redistribution.

### AIM4

AIM4 remains frozen and untouched as the first structured decision-layer baseline:

```text
CARDINALITY_TOPK_V1
```

It reconstructs the actual S1 normalized-margin decision semantics, predicts a hard answer cardinality from `(s1,s2,s3,s4,n_nonnegative)`, then takes the top-k raw normalized margins.

AIM4 is **not** currently the preferred S2 successor because later review identified two limits:

- it discards semantic action identity at the decision layer and collapses cardinality uncertainty to one hard `k` before set construction;
- its original meta-evaluation is not fully nested with respect to the outer subject fold.

### AIM5 — current frontier

AIM5 is now frozen before execution:

```text
NESTED_ACTION_AWARE_CONDITIONAL_SETMAP_V1
```

It keeps all S1 evidence generation fixed and adds only a nested decision operator:

```text
S1 normalized margins + semantic action identities
    -> nested shared-slope/action-intercept candidate utilities
    -> nested full cardinality distribution q(k)
    -> exact conditional SET-MAP over 15 nonempty option subsets
```

The normalized set model is:

\[
P(S\mid m,a)
=
q_{|S|}(m)
\frac{\exp(\sum_{i\in S}\ell_i)}
{\sum_{T:|T|=|S|}\exp(\sum_{j\in T}\ell_j)}.
\]

For every outer fold, all decision-layer training margins are regenerated by inner held-out scoring from base models that exclude both the outer fold and the inner fold. The outer-test fold is absent from both base-model and meta-model training.

AIM5 keeps the AIM4 support bar unchanged:

```text
pooled exact-set delta >= +0.05
nonnegative delta in >= 4/5 outer folds
subject-cluster bootstrap 95% CI lower bound > 0
```
