## Current research compression

The experimental line now supports a typed chain:

```text
represented distinctions
    -> attainable semantic adequacy
    -> counterfactual consequence sufficiency
    -> learned transition interface
    -> predictive counterfactual sufficiency
    -> goal-authority interface
    -> plan selection
    -> behavior
```

The current object should **not** be collapsed into one representation-quality, world-model-quality, liveness, or planner-quality scalar.

The strongest reusable distinctions are:

\[
\boxed{
\begin{aligned}
R(f) &\neq A(f;\mathcal J),\\
A(f;\mathcal J) &\neq CF_h(f;\mathcal J,\mathcal A),\\
CF_h &\neq PCF_h(f,P),\\
\text{prediction error amount} &\neq \text{error location} \neq \text{semantic damage},\\
\text{latent heuristic} &\neq \text{semantic adjudicator},\\
\text{available distinction} &\neq \text{authorized distinction}.
\end{aligned}
}
\]

Two current laws carry the most weight:

> **A world model cannot recover distinctions its state representation erased. But even when the state contains enough information, learned dynamics can destroy the distinction before the consequence is queried.**

> **A planner may use latent geometry to search. It may not silently use that geometry to define what the authorized goal means.**

\[

# Goal semantics and authority

## Goal-0.1 — latent centroid sufficiency attack

`SEMANTIC_GOAL_SUFFICIENCY_V0.1 = LATENT_GOAL_CONTRAST_NOT_IDENTIFIED`.

The frozen latent scorer was squared Euclidean distance from an occupied 3-bit code to the centroid of all codes in the semantic goal class.

On the original learned geometry:

- 119/124 testable predictor-task cells strictly preserved GOOD-over-BAD ordering;
- 0 strict reversals;
- 0 cross-class ties;
- all 22 selected encoders globally separated both binary goal classes by centroid distance.

Therefore the intended `LATENT_GOAL_ORDERING_NOT_SEMANTICALLY_SUFFICIENT` witness was **not** identified.

However, the latent metric sometimes strictly refined futures that the binary goal treated as equivalent. That opened an authority question, not a sufficiency failure.

`LATENT_GOAL_METRIC_REPRESENTATION_SENSITIVE_V0.1 = SUPPORTED`.

## Goal authority interface

`GOAL_AUTHORITY_INTERFACE_V0.1 = SUPPORTED_FINITE`.

Primary jurisdiction:

\[
I_{\mathcal J}(\pi)=\operatorname{goal\_miss}(\pi).
\]

On the frozen finite terrain, this is minimal and sufficient for the binary goal jurisdiction.

Adding an independently constituted secondary objective,

\[
K(\pi)=\#\{\text{non-noop actions}\},
\]

with lexicographic priority after primary goal attainment, changes the minimal interface to:

\[
I_{\mathcal J+\mathcal K}(\pi)
=
(\operatorname{goal\_miss}(\pi),K(\pi)).
\]

`I_J` is insufficient for `J+K`.

Both semantic interfaces are representation-isomorphism invariant over the inherited coordinate-relabeling domain.

The centroid score is typed:

```text
LATENT_HEURISTIC = proposal/search metadata
SEMANTIC_GOAL_SELECTOR = authority-bearing comparison
```

On the original trained coordinates, centroid selection preserved the primary binary minimum in all 124 audited cells but violated the newly constituted `J+K` minimum in 105/124 cells if promoted to final adjudication.

Current planner principle:

> **The semantic interface should grow when authority grows—not when the latent representation happens to contain another distinction.**

## Goal authority behavior — nondominated attempt

`GOAL_AUTHORITY_BEHAVIOR_NONDOMINATED_V0.1 = CONTRAST_NOT_IDENTIFIED`.

The target again required genuine state change, \(g=-A(z_0)\), and successfully removed the noop escape hatch on 258 predictor tasks.

\[

- 255/258 had multiple Pareto-frontier plans;
- **0/258** had multiple incomparable Pareto objective tuples;
- the only frontier tuples were `(1,0)` and `(2,1)`, one tuple per task.

No true outcomes were opened.

Therefore:

```text
H_NONDOMINATED_BEHAVIOR = OPEN_NOT_TESTED
K_R_PARETO_TRADEOFF = NOT_IDENTIFIED
```

Failure locus:

```text
AUTHORITY CONSTITUTION / SECONDARY-OBJECTIVE GEOMETRY
```

Do not repair this experiment in place.

A legitimate successor needs prospectively constituted resource coordinates that can vary independently. Separate read-action burden and write-action burden is a plausible candidate, but remains **UNOPENED**.

Compression:

> **Multiple admissible plans are not the same thing as multiple authorized tradeoffs. To test nondominated authority, the constituted objectives themselves must vary independently.**
