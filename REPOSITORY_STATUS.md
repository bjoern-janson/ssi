## Freeze discipline

Scientific experiments should preserve this order when applicable:

```text
SPEC
-> CASES
-> BINDINGS / CANDIDATE
-> INDEPENDENT ORACLE
-> PROTOCOL
-> EVALUATOR
-> FIRST RESULT
```

Rules:

1. Do not modify frozen upstream artifacts after first execution.
2. Do not silently repair a failed first result.
3. Do not let candidate outputs define the oracle.
4. Do not let the protocol issue evaluator judgments.
5. Do not scalarize independent typed obligations merely to rescue a claim.
6. Preserve administrative incidents separately from scientific mutations.
7. State the strongest earned claim and the explicit authority ceiling.
8. A later repair receives a new prospective object or lineage; it does not rewrite the earlier result.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the operational version.
