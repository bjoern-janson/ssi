## Cross-regime jurisdiction-comparability gate

A second audited semantic-equivalence regime does **not** automatically authorize comparison.

Comparability requires all of:

1. purpose/proposition compatibility;
2. constituted carrier alignment;
3. compatible relation and operation typing;
4. target-independent transport.

If source carriers differ, a transport:

\[
\tau_r:S_r\to S_\ast
\]

is itself a semantic object requiring authority.

Only after transport is constituted may one form:

\[
\widetilde{\equiv}_r
=
(\tau_r\times\tau_r)(\equiv_r)
\]

\[
\boxed{
\equiv_\Box^{\rm cross}

\bigcap_r\widetilde{\equiv}_r.
}
\]

If the gate fails, report:
