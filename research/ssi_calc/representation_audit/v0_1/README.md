# SSI-CALC `REPRESENTATION_AUDIT` v0.1

A small, purpose-indexed representation-conformance extension.

It answers one question:

> Which distinctions of a constituted observable survive the supplied representation quotient for purpose `kappa`?

Implemented:

- `CHECK_SUFFICIENCY`
- `CHECK_MASK_SUFFICIENCY`

Reserved only:

- `CHECK_ALTERNATIVE_FRONTIER`
- `PREDICT_CONSEQUENCE`

The checker is finite and non-learning. It never treats predictive performance as authority.

Run:

```bash
python run_benchmark.py
```
