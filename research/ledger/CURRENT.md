# CORE THEORY

## Central non-collapse

```text
representation != authority != prediction != behavior
observable != authorized != consequential
semantic authority != licensed advisory information != behavioral consequence
```

A system can:

1. contain a distinction;
2. preserve a distinction;
3. use a distinction;
4. benefit operationally from a distinction;
5. be entitled to use a distinction for judgment.

These are different properties.

## Interface sufficiency law

> **An interface is sufficient only if it preserves every distinction that the downstream jurisdiction is entitled to adjudicate.**

The required distinction may concern a component interaction, alignment, intervention identity, future horizon, semantic error location, goal denotation, route profile, or provenance.

## Authority law

> **Available information does not acquire semantic authority merely by being available, predictive, geometrically salient, behaviorally consequential, historically detailed, or operationally useful.**

Related non-collapses:

```text
validated consequence grants local authority; it does not automatically grant causal authority
latent heuristic != semantic adjudicator
selected witness != semantic denotation
semantic state != semantic provenance
maximum provenance != minimal authority interface
behavioral usefulness = evidence for utility, not evidence for jurisdiction
```

## Equivalence structure

The opportunity/provenance/freedom line distinguishes:

```text
~auth : indistinguishable for the constituted authority
~pred : indistinguishable to the learned predictor/interface
~beh  : indistinguishable under downstream execution
```

Empirically:

```text
~auth does not imply ~beh
~pred does not imply ~auth
behavioral/state-history distinction does not itself grant authority
```

The freedom experiment establishes that an authority quotient may intentionally leave real policy degrees of freedom unresolved.

## Licensed advisory information

`GOAL_AUTHORITY_ADVISORY_SELECTION_V0.1` adds the positive middle that was previously missing.

The frozen architecture is:

```text
semantic authority
    -> authorized equivalence class
    -> licensed advisory information
    -> representative choice
    -> held-out behavior
```

The advisory license is role-restricted:

```text
H : [pi]_auth -> ranking of representatives
```

with the invariants:

```text
H does not change admissibility
H does not change frontier membership
H does not change I_auth
H does not change the authority equivalence relation
```

The experimentally earned law is:

> **A distinction may be legitimately useful under a narrower implementation license than semantic adjudication.**

and the anti-leakage law is:

> **Operational usefulness does not retroactively enlarge semantic authority.**

`License(H,J)` is therefore a useful **candidate abstraction** for a role-restricted permission to refine choices within `J`-equivalence classes. Its transfer across different jurisdictions is **unopened** and must not be treated as a theorem.

### Provenance authority quotient

The constituted reference is:

```text
T(pi) = (predicted_goal_miss, R_read, R_write)
```

At fixed horizon `h=3`, `R_read + R_write = 3`. Therefore the semantic authority quotient has multiple exact coordinate serializations:

```text
I_read  = (predicted_goal_miss, R_read)
I_write = (predicted_goal_miss, R_write)
```

Both are exact and coordinate-minimal on this terrain. The full three-coordinate tuple is exact but coordinate-redundant.

Ordered READ/WRITE history and exact action-name history are sufficient but over-refine the constituted authority relation.

### Advisory selection

`GOAL_AUTHORITY_ADVISORY_SELECTION_V0.1` froze 32 finite implementation worlds and all 16 exact authority classes per world, for 512 implementation-world x authority-class cells.

The advisory signal saw only 24 independent primitive-action calibration trials per action and was restricted to selecting a representative inside the frozen class. Held-out plan execution used a disjoint random stream.

Results:

```text
ADVISORY mean held-out success  = 60.01%
NEUTRAL mean held-out success   = 43.93%
SHUFFLED_H mean held-out success = 44.23%

ADVISORY - NEUTRAL   = +16.08 percentage points
ADVISORY - SHUFFLED_H = +15.78 percentage points
SHUFFLED_H - NEUTRAL = +0.30 percentage points

authority leakage events = 0
```

Paired cell signs:

```text
ADVISORY vs NEUTRAL:   418 wins / 60 losses / 34 ties
ADVISORY vs SHUFFLED_H: 407 wins / 67 losses / 38 ties
```

The shuffled control preserves class composition, score distribution, and selector machinery while destroying the evidence-to-implementation correspondence. Nearly all of the gain disappears.

Thus the useful causal object is not merely `extra signal`; it is approximately:

```text
evidence x licensed decision slot
```

This does **not** promote action reliability, calibration evidence, or held-out success into semantic authority.
