# CURRENT MASTER CANDIDATE

## Scope-indexed entitlement

The current conceptual center is not an intrinsic type attached to information. It is a scoped judgment about what causal effect a distinction is entitled to exercise:

```text
Gamma |- (d ->[operation] effect) @ scope
```

The governing non-collapses are:

```text
access != causal influence != licensed effect
endpoint legality != role license != execution entitlement
capability != entitlement != actual exercise
Can != May != Did
```

Information can remain present and true while its entitlement to affect a decision changes.

The current causal-envelope notation is:

```text
R(T,sigma) = RealizableEffects / Can
C(Gamma,sigma) = EntitledEffects / May
W(T,Gamma,sigma) = R intersect C = warranted executable envelope
Q(Gamma,sigma) = required warranted envelope
A(T) = ActualEffects / Did
```

Candidate execution contract:

```text
Q subseteq W
A subseteq W
```

Interpretation:

- `Q not subseteq W` -> under-realization: the system cannot realize everything the current scope warrants and requires.
- `A not subseteq W` -> over-exercise: the system caused something outside the warranted executable envelope.

Compact research law:

> **Improve Can. Justify May. Constrain Did.**

Candidate master formulation:

> **Safe self-improvement is warrant-bounded causal expansion.**

This is a conceptual/formal candidate. It is not an SSI-CALC rule and is not claimed as a general empirical theorem.

## Quotients and licensed optimization

A jurisdiction `J` induces authority-equivalence classes. Authorized equivalence is a **decision quotient**, not a world quotient: plans can be equivalent for adjudication while remaining behaviorally distinct downstream.

A role-scoped advisory mechanism may rank representatives inside a constituted class:

```text
H_C : C -> Rank(C)
```

The Relicense Calculus strengthened endpoint membership to the candidate-domain invariant:

```text

before
S(H,J,C) in C
```

F5 then showed this is still only a selection-domain projection of a more general causal-footprint constraint.
